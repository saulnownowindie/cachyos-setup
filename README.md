# CachyOS Setup

Automatización de configuración post-instalación para CachyOS KDE.

Este proyecto instala y configura un entorno completo para desarrollo,
edición multimedia, gaming y uso diario.

## Características

### Sistema
- Actualización del sistema
- Configuración básica de CachyOS
- Herramientas esenciales

### Desarrollo
- Git
- GitHub CLI
- Node.js
- npm
- pnpm
- Bun
- Docker
- VS Code / Code OSS

### Multimedia
- FFmpeg
- OBS Studio
- Kdenlive
- GIMP
- Inkscape
- DaVinci Resolve (opcional)
- AutoSubs para DaVinci Resolve

### KDE Plasma
- Configuración de Dolphin
- KDE Connect
- Utilidades KDE

### Gaming
- Steam
- Heroic Games Launcher
- Herramientas necesarias

### Sincronización y backups
- Syncthing
- Backup de configuraciones importantes
